## General Guidelines for All Prompts:

### Technical Specs:

- **Resolution**: Request 1920x1080 or higher for presentation quality
- **Orientation**: Primarily portrait for phone screens, some landscape
- **File Format**: PNG with transparency support where applicable

### Design Consistency:

- **Hedera Brand Colors**:
  - Primary: #00D4AA (teal green)
  - Secondary: #FFFFFF (white)
  - Accent: #222222 (dark gray)
- **Phone Model**: Modern smartphone (iPhone 14/15 Pro or Samsung Galaxy S23 style)
- **Screen Quality**: OLED-like clarity, high contrast, readable text
- **Lighting**: Professional, even lighting highlighting screen content

### Content Requirements:

- ✅ Phone screen always clearly visible and in focus
- ✅ Hedera logo/branding visible in each image
- ✅ UI text must be crisp and readable
- ✅ Professional hands holding phone (business casual context)
- ✅ Modern, clean interface design
- ✅ Suitable for investor/judge presentation deck

### Usage Context:

- Hedera Hackathon pitch presentation
- Demonstrates AR agent + crypto payment integration
- Shows user journey from discovery → payment → confirmation
- Highlights Hedera network as payment rail

## Tips for Best Results:

1. **Add "photorealistic" or "professional photograph"** to ensure realistic rendering
2. **Specify "phone screen facing camera"** to get the desired viewing angle
3. **Include "clearly visible" or "in focus"** for screen content
4. **Mention "presentation quality" or "pitch deck ready"** for polish
5. **Use "Hedera logo" explicitly** to ensure brand presence
6. **Request "readable text"** to avoid blurry UI elements
7. **Add "modern UI design"** for contemporary look
8. **Include lighting specifications** (natural, professional, studio) for consistency

## Post-Generation Editing:

- Add real Hedera logo overlay if AI-generated logos aren't perfect
- Enhance screen brightness/contrast for better visibility
- Add text overlays with actual HBAR amounts if needed
- Ensure brand color accuracy (#00D4AA)
